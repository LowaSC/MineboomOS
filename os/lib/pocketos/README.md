# PocketOS

Мини-ОС для CC:Tweaked: панель задач, стартовое меню, многозадачность, обои, темы.
Работает на карманных компьютерах (26×20) и на стандартных компьютерах с внешним монитором.

## Структура библиотеки

```
os/lib/pocketos/
├── init.lua       — точка входа, event loop, поддержка монитора, маршрутизация событий
├── shell.lua      — общий рендер + темы + desktop.db
├── desktop.lua    — рабочий стол с иконками приложений
├── taskbar.lua    — панель задач (Start, приложения, громкость, часы)
├── startmenu.lua  — стартовое меню (INSTALLED / SYSTEM + Reboot)
├── modal.lua      — модальные окна (theme, wallpaper, volume, scale, tray)
├── wm.lua         — запуск, окна приложений, закрытие приложений
└── README.md      — эта документация
```

Каждый визуальный компонент изолирован: можно править taskbar, не трогая остальное.

## Быстрый старт

```lua
-- computer/XX/main.lua
local cfg      = dofile("config.lua")
local PocketOS = dofile("/os/lib/pocketos/init.lua")

local pos = PocketOS.create(cfg)
pos:registerApp(dofile("/os/apps/factory.lua"))
pos:registerApp(dofile("/os/apps/storage.lua"))
pos:run()   -- не возвращает управление
```

В централизованной схеме симлинки `lib/pocketos` и `lib/ui_framework` больше не
нужны: ОС грузится из `/os`, данные остаются в `/data`.

## Конфигурация (config.lua)

| Ключ               | Тип    | Описание                                          |
|--------------------|--------|---------------------------------------------------|
| `modemSide`        | string | Сторона модема (`"back"`, `"top"`, …)             |
| `monitorSide`      | string | Сторона внешнего монитора (необязательно)         |
| `useMonitor`       | bool   | Автопоиск монитора через `peripheral.find`        |
| `monitorTextScale` | number | Масштаб текста монитора (0.5–5, необязательно)    |
| `refreshSeconds`   | number | Интервал обновления данных                        |
| `scrollStep`       | number | Строк за одну прокрутку колёсиком                 |

### Только карманный компьютер (без монитора)

```lua
return {
    modemSide = "back",
    refreshSeconds = 5,
    scrollStep = 3,
    -- остальные параметры приложений...
}
```

### Стандартный компьютер с монитором

```lua
return {
    modemSide        = "back",
    monitorSide      = "top",
    monitorTextScale = 0.5,
    refreshSeconds   = 5,
    scrollStep       = 3,
    -- остальные параметры приложений...
}
```

## Интерфейс приложения

Каждое приложение — Lua-файл, возвращающий таблицу:

```lua
local M = {}
M.id        = "myapp"          -- уникальный идентификатор
M.name      = "My App"         -- название в меню
M.icon      = "MA"             -- 2 символа для панели задач
M.protocols = {"my_protocol"}  -- Rednet-протоколы (для rednet.open)

-- Инициализация: вызывается при открытии приложения.
-- win     — окно рабочей области (workArea)
-- ctx     — { config, send(id,msg,proto), broadcast(msg,proto), openRednet() }
-- Возвращает: state (произвольная таблица)
function M.init(win, ctx)
    return {}
end

-- Обработка событий.
-- Возвращает: state (обновлённый), needsDraw (bool)
-- Нормализация mouse_click/monitor_touch: p1=button, p2=x, p3=y
function M.onEvent(state, event, p1, p2, p3, p4)
    return state, false
end

-- Отрисовка в win.
function M.draw(state, win)
end

-- Необязательно: вызывается при закрытии приложения.
function M.onClose(state)
end

return M
```

## Управление

| Действие                       | Результат                                                |
|--------------------------------|----------------------------------------------------------|
| Клик `[>]` в taskbar           | Открыть / закрыть стартовое меню                         |
| Клик `[-]` в шапке приложения  | Свернуть приложение на рабочий стол                      |
| Клик `[x]` в шапке приложения  | Закрыть приложение                                       |
| Клик на иконку громкости/часы  | Открыть быстрый системный лоток (громкость + scale)      |
| Клик на иконку на десктопе     | Запустить приложение                                     |
| Клик на приложение в меню Пуск | Запустить или переключиться                              |

## Settings

Раздел `Modem` в приложении Settings задаёт сторону модема вручную. Значение
сохраняется в `/data/desktop.db`, применяется сразу через `rednet.open(side)` и
переживает перезагрузку. Если значение не задано, используется `cfg.modemSide`.
| Клик на кнопку в taskbar       | Переключиться на приложение                              |
| ПКМ на кнопку в taskbar        | Закрыть приложение                                       |
| Backspace                      | Закрыть открытый модал / стартовое меню                  |
| Клик вне модала                | Закрыть модал                                            |
| Прокрутка колёсиком            | Маршрутизируется в верхнее окно (модал → меню → app)     |
| Shift + прокрутка              | Горизонтальный скролл (p4=true для приложения)           |
| Reboot (меню Пуск)             | Перезагрузить компьютер                                  |

## Окна приложений

PocketOS рисует системную шапку активного приложения сама. В `init(win, ctx)`
приложение получает не всю рабочую область, а дочернее окно под шапкой ОС:
первая строка рабочей области зарезервирована под `[-]`, название приложения и
`[x]`. Координаты mouse/monitor событий, которые приходят в `onEvent`, уже
сдвинуты в координаты окна приложения.

## Настройки и системный лоток

Громкость и Scale доступны двумя способами:
- **Быстро** — клик по иконке громкости или часам в taskbar → лоток поверх
- **Полно** — приложение Settings → разделы Theme / Wallpaper / Volume / Scale

Темы и обои меняются только из Settings (открывают модал-список).
Любое изменение сразу сохраняется в `desktop.db` и применяется live (включая текстовый масштаб монитора).

## Системные и установленные приложения

Приложение помечается системным флагом `M.system = true`.
В стартовом меню системные показываются в разделе `SYSTEM`, остальные — в `INSTALLED`.
Системные приложения нельзя удалить через App Store.

## Данные рабочего стола (desktop.db)

Хранится в `/data/desktop.db`. Формат:

```lua
{
    themeIndex = 1,            -- индекс темы из ui_framework/themes.lua
    bgColor    = colors.black, -- фоновый цвет обоев
    fgColor    = colors.gray,  -- цвет узора обоев
    pattern    = "stars",      -- "solid" | "dots" | "stars" | "grid" | "tiles"
}
```

## Добавление нового компьютера

1. Установить `/startup.lua` через `/os/install.lua` или временный symlink на `/os`
2. Добавить ID компьютера в `/os/config/computers.lua`
3. Указать `role = "pocketos"` и список приложений `apps = {...}`
4. Перезагрузить компьютер
